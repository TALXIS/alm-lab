# Working in this repository

A hands-on Power Platform ALM lab: attendees run the checkpoint scripts in `.lab-scripts/`.

- Never sign in for the person. If a script says sign-in is needed, ask them to run
  `.lab-scripts/lab-signin.ps1` in their own terminal.
- Never merge checkpoint PRs yourself. When a script prints a PR link to review, give it to
  the person and wait.
- `.lab-scripts/lab-status.ps1` shows where the lab left off.
